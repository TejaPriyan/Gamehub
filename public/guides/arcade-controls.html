Start playing and keep control of the arcade

Choose a game, understand its input and keep local progress.

By Teja Priyan · Updated 27 October 2026

Choose a game before pressing Play

Each game detail screen explains its objective and controls. Start there rather than assuming every canvas uses the same keys. Neon Pulse and Quantum Drift use lane or steering input; Cyber Invaders uses movement and firing; Grav-Runner changes the direction of gravity. The skills transfer between games, but the exact controls differ.

  1. Open a game detail page and read the controls before starting. On a phone, look for the touch controls shown by the game.
  2. Click or tap the game so it receives focus. The arcade prevents common movement keys from scrolling the page while you are playing.
  3. Use the displayed fullscreen control or F where available. Exit browser fullscreen with Escape when you need the surrounding page again.
  4. Start slowly and identify what ends a run: collisions, a missed path or an incoming projectile. Practice one mechanic at a time.
  5. After finishing, compare the score with your local record. Keep the same browser profile if you want to retain it.

Troubleshoot input and sound

If keys scroll the page instead of moving the character, click inside the game and try again. Close other dialogs that might have keyboard focus. On a touch device, use the in-game input area rather than browser navigation gestures near the edge.

A browser can require an intentional interaction before playing synthesized audio. Click Play and check the game’s sound control and device volume. If animation becomes uneven, close heavy tabs and reduce the display workload before starting a new run. Clearing site data removes stored cards and local scores; private browsing may discard them when the session ends.
